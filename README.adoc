= gwt

A git worktree helper...

== Installation

[source,sh]
----
curl --proto '=https' --tlsv1.2 -sSf https://raw.githubusercontent.com/sjwall/gwt/main/install.sh | sh
----

== Commands

* `gwt [add] [--ide <ide>] <name>`: Create a worktree `../gwt-<dir-name>/<name>`, change directory to it, run `yarn` if `yarn.lock` exists, and launch the configured IDE (defaults to `nvim`). Use `--ide <ide>` to override the IDE for this run only, or `--ide none` to skip launching the IDE. If the repository is located in an unsuitable path (e.g. within a hidden directory such as `~/.local`), you will be prompted for a safe parent directory.
* `gwt pull [--ide <ide>] <name>` / `gwt p [--ide <ide>] <name>`: Fetch `origin/<name>`, create a tracking worktree, cd, yarn, launch configured IDE (supports `--ide <ide>` or `--ide none`).
* `gwt cd <name>`: Switch to a worktree matching `<name>` (searches current repository and all tracked repositories).
* `gwt ls` / `gwt list`: List all tracked worktrees.
* `gwt remove <name>` / `gwt rm <name>`: Remove worktree `<name>` (`-f` or `-force` supported).
* `gwt config [key] [value]` / `gwt ide [name]`: View or set configuration options (e.g. `gwt config ide code` or `gwt ide code`). Configured IDE defaults to `nvim`.

== Configuration

* Tracked repositories are stored in `${XDG_CONFIG_HOME:-~/.config}/gwt/repos`.
* Custom worktree parent locations for repositories in unsuitable paths are stored in `${XDG_CONFIG_HOME:-~/.config}/gwt/locations`.
* Configuration settings are stored in `${XDG_CONFIG_HOME:-~/.config}/gwt/config`.
