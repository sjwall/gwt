= gwt

A git worktree helper...

== Installation

[source,sh]
----
curl --proto '=https' --tlsv1.2 -sSf https://raw.githubusercontent.com/sjwall/gwt/main/install.sh | sh
----

The installer:
* Clones or updates the `gwt` repository into `~/.local/share/gwt` (or `$GWT_DIR`).
* Adds the sourcing line to your shell configuration (`.zshrc`, `.bashrc`, etc.).
* Prompts you to optionally symlink bundled agent skills to your global agent configurations.

=== Agent Skills Symlinking

During installation, you can link the `gwt` skill to your global agent environments:

* `1) agents`: Symlinks to `${AGENTS_CONFIG_DIR:-~/.agents}/skills`
* `2) opencode`: Symlinks to `${OPENCODE_CONFIG_DIR:-~/.config/opencode}/skills`
* `3) claude`: Symlinks to `${CLAUDE_CONFIG_DIR:-~/.claude}/skills`
* `4) gemini`: Symlinks to `${ANTIGRAVITY_CONFIG_DIR:-~/.gemini/antigravity-cli}/skills` and `${GEMINI_CONFIG_DIR:-~/.gemini/config}/skills`
* `5) all`: Symlinks to all supported environments
* `6) none`: Skips symlinking (default when pressing Enter)

You can select multiple targets by number or name (e.g. `1,3`, `claude, gemini`, or `all`).

=== Installer Options & Unattended Install

You can pass arguments to the installer or configure it using environment variables:

[source,sh]
----
# Install with all agent skills symlinked
curl -sSf https://raw.githubusercontent.com/sjwall/gwt/main/install.sh | sh -s -- --skills=all

# Install for specific agents without prompting
curl -sSf https://raw.githubusercontent.com/sjwall/gwt/main/install.sh | sh -s -- --skills=claude,gemini

# Skip skill symlinking
curl -sSf https://raw.githubusercontent.com/sjwall/gwt/main/install.sh | sh -s -- --no-skills

# Perform a dry run without making changes
curl -sSf https://raw.githubusercontent.com/sjwall/gwt/main/install.sh | sh -s -- --dry-run

# Run locally from a cloned repository
./install.sh --skills=all
----

==== Command Line Options

* `--skills=<targets>`: Comma-separated list of targets to link (`agents`, `opencode`, `claude`, `gemini`, `all`, `none`).
* `--no-skills`: Skip skills symlinking (same as `--skills=none`).
* `--dir=<path>`: Custom installation directory (default: `~/.local/share/gwt`).
* `-n`, `--dry-run`: Perform a dry run without making any changes.
* `-h`, `--help`: Show installer help and options.

==== Environment Variables

* `GWT_SKILLS`: Target list for skills symlinking (e.g. `GWT_SKILLS="all"` or `GWT_SKILLS="agents,claude"`). Useful for non-interactive or automated installs.
* `GWT_DIR`: Custom install directory (default: `${XDG_DATA_HOME:-~/.local/share}/gwt`).
* `GWT_REPO_URL`: Custom repository clone URL.
* `GWT_BRANCH`: Git branch to install (default: `main`).

== Commands

* `gwt [add] [--ide <ide>] [--agent [<agent>] | -a [<agent>]] [--no-install] <name>`: Create a worktree `../gwt-<dir-name>/<name>`, change directory to it, run `yarn` if `yarn.lock` exists, and launch the configured IDE (defaults to `nvim`) or configured agent. Use `--ide <ide>` to override the IDE for this run only, or `--ide none` to skip launching the IDE. Use `--agent` or `-a` (with or without a named agent, e.g. `--agent <agent>`, `-a <agent>`, `--agent=<agent>`, or `-a=<agent>`) to launch the agent instead of the IDE (supports `--agent none` or `-a none` to suppress launching). Use `--no-install` to skip running `yarn`. If the repository is located in an unsuitable path (e.g. within a hidden directory such as `~/.local`), you will be prompted for a safe parent directory.
* `gwt pull [--ide <ide>] [--no-install] <name>` / `gwt p [--ide <ide>] [--no-install] <name>`: Fetch `origin/<name>`, create a tracking worktree, cd, yarn, launch configured IDE (supports `--ide <ide>` or `--ide none`, and `--no-install`).
* `gwt cd <name>`: Switch to a worktree matching `<name>` (searches current repository and all tracked repositories).
* `gwt main [<name>]` / `gwt m [<name>]`: Switch to the main repository matching `<name>` (defaults to the main repository of the current worktree; searches tracked repositories if `<name>` is provided).
* `gwt M [<name>]` / `gwt M [--ide <ide>] [<name>]`: Switch to the main repository matching `<name>` and launch configured IDE (defaults to the main repository of the current worktree; searches tracked repositories if `<name>` is provided; supports `--ide <ide>` or `--ide none`).
* `gwt switch [--ide <ide>] <name>` / `gwt s [--ide <ide>] <name>`: Switch to a worktree matching `<name>` and launch configured IDE (supports `--ide <ide>` or `--ide none`).
* `gwt agent [--agent <agent>] <name>` / `gwt a [--agent <agent>] <name>`: Switch to a worktree matching `<name>` and launch configured agent (prompts for agent command on first run if not configured; supports `--agent <agent>` or `--agent none`).
* `gwt ls [<name>]` / `gwt list [<name>]`: List tracked worktrees (optionally filtered by repository `<name>`).
* `gwt remove [<name>]` / `gwt rm [<name>]`: Remove worktree (defaults to current worktree when run from within one; changes directory to the main repository and removes the worktree). `-f` or `-force` supported.
* `gwt track [<path>]` / `gwt t [<path>]`: Track a git repository (defaults to the current repository).
* `gwt config [key] [value]` / `gwt ide [name]`: View or set configuration options (e.g. `gwt config ide code` or `gwt ide code`). Configured IDE defaults to `nvim`.
* `gwt upgrade`: Upgrade the gwt repository (`git pull` and reload `gwt.sh`).

== Configuration

* Tracked repositories are stored in `${XDG_CONFIG_HOME:-~/.config}/gwt/repos`.
* Custom worktree parent locations for repositories in unsuitable paths are stored in `${XDG_CONFIG_HOME:-~/.config}/gwt/locations`.
* Configuration settings are stored in `${XDG_CONFIG_HOME:-~/.config}/gwt/config`.

== Autocompletion

`gwt` includes built-in Zsh autocompletion support. When `gwt.sh` is sourced or `_gwt` is present in your `$fpath`, pressing `<TAB>` will automatically suggest:

* Subcommands (`add`, `pull`, `p`, `cd`, `main`, `m`, `M`, `switch`, `s`, `agent`, `a`, `ls`, `list`, `remove`, `rm`, `track`, `t`, `config`, `ide`, `upgrade`)
* Worktree names and paths for `gwt cd`, `gwt switch`, `gwt agent`, and `gwt remove`
* Tracked repository names and paths for `gwt main` and `gwt M`
* Remote branches from `origin` for `gwt pull`
* Branches for `gwt add`
* Subcommands and configuration keys for `gwt config`
* Configured IDE and agent options for `gwt ide`, `--ide`, and `--agent` / `-a` flags


== Exit Codes

The `gwt` utility returns `0` upon success and unique non-zero exit codes for specific error conditions:

[cols="1,2,5", options="header"]
|===
| Exit Code | Command / Category | Description
| `0` | Success | Command completed successfully.
| `1` | `cd` | Invalid argument count (expected exactly 1 argument).
| `2` | `cd` | Multiple matching worktrees found in current repository.
| `3` | `cd` | Multiple matching worktrees found across tracked repositories.
| `4` | `cd` | No matching worktree found for query.
| `5` | `main` | Not inside a git repository and no repository specified or found.
| `6` | `main` | Invalid argument count (more than 1 argument provided).
| `7` | `main` | Multiple exact repository matches found.
| `8` | `main` | Multiple repository name matches found.
| `9` | `main` | Multiple repository path matches found.
| `10` | `main` | No matching repository found for query.
| `11` | `switch` | Missing required argument for `--ide` option.
| `12` | `switch` | Invalid argument count (expected exactly 1 worktree name).
| `13` | `remove` | Cannot remove main repository (a worktree target must be specified).
| `14` | `remove` | Failed to change directory to main repository before removal.
| `15` | `remove` | `git worktree remove` command failed.
| `16` | `pull` | Missing required argument for `--ide` option.
| `17` | `pull` | Invalid argument count (expected exactly 1 branch name).
| `18` | `pull` | Failed to determine target worktree directory location.
| `19` | `pull` | Failed to create worktree parent directory.
| `20` | `pull` | `git fetch origin` command failed.
| `21` | `pull` | `git worktree add` command failed.
| `22` | `pull` | Failed to change directory to newly created worktree.
| `23` | `add` | Missing required argument for `--ide` option.
| `24` | `add` | Invalid argument count (expected exactly 1 branch name).
| `25` | `add` | Failed to determine target worktree directory location.
| `26` | `add` | Failed to create worktree parent directory.
| `27` | `add` | `git worktree add` command failed.
| `28` | `add` | Failed to change directory to newly created worktree.
| `29` | `config` | Invalid argument count for `gwt config get` (expected exactly 1 key).
| `30` | `config` | Specified configuration key not found in `gwt config get`.
| `31` | `config` | Invalid argument count for `gwt config set` (expected key and value).
| `32` | `config` | Invalid argument count for `gwt config unset` (expected exactly 1 key).
| `33` | `config` | Specified configuration key not found in `gwt config <key>`.
| `34` | `upgrade` | `gwt` repository not found at target directory.
| `35` | `upgrade` | `git pull` command failed during upgrade.
| `36` | `track` | Not inside a git repository and no repository specified.
| `37` | `track` | Invalid argument count (more than 1 argument provided).
| `38` | `track` | Specified path is not a git repository.
| `39` | `list` | Invalid argument count (more than 1 repository specified).
| `40` | `list` | Multiple exact repository matches found.
| `41` | `list` | Multiple repository name matches found.
| `42` | `list` | Multiple repository path matches found.
| `43` | `list` | No matching repository found for query.
| `44` | `agent` | Missing required argument for `--agent` option.
| `45` | `agent` | Invalid argument count (expected exactly 1 worktree name).
| `46` | `agent` | No agent configured.
|===
